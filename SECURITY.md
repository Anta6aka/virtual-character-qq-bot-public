# Security policy

This project automates a QQ account through AstrBot and NapCat. Treat every
deployment as security-sensitive.

- Never put tokens, cookies, API keys, QQ passwords, or real account IDs in the
  repository or in an issue.
- Keep `cmd_config.json`, `relationship.json`, `connection_guard.json`, the
  token file, databases and logs outside Git.
- Report a vulnerability privately to the maintainer instead of filing a public
  issue with exploit details.
- Make sure your use complies with the QQ/NapCat/AstrBot terms of service.
